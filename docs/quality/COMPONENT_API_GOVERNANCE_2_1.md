## Composition Flow

A new application should read the component model from top to bottom:

1. `TLazRibbonForm` connects the form shell to `TLazRibbon` and an optional `TLazRibbonSkinManager`.
2. `TLazRibbon` owns the Office surface: Application Button, Quick Access Toolbar, tabs, BackStage link and global Ribbon behavior.
3. Tabs contain panes; panes contain commands, galleries, skin galleries, separators or hosted controls.
4. BackStage is linked through `TLazRibbon.BackstageView`; navigation and commands live in `TLazRibbonBackstageView.Buttons`, while pages are content containers.
5. Skins are owned by `TLazRibbonSkinManager`; controls connect to the manager through `SkinManager` and select skins with name-based properties.
