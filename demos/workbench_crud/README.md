# LazRibbon Workbench CRUD Demo

This demo is a practical application-style sample for LazRibbon. It combines:

- `TLazRibbonForm`
- `TLazRibbon`
- Quick Access Toolbar
- `TLazRibbonBackstageView`
- `TLazRibbonBackstageRecentList`
- `TLazRibbonSkinManager`
- `TLazRibbonSkinGalleryItem`
- `TLazRibbonPopupMenu`
- normal LCL client controls such as `TStringGrid`, edits, combo boxes and buttons

The goal is not to implement persistence. The data is in memory so the project
can be compiled and opened immediately after installing the package.
