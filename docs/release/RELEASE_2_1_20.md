# LazRibbon 2.1.20

- **Date Edit** adds an LCL calendar selector with an optional date, keyboard
  shortcuts, `ReadOnly` and an `OnChange` event. Try it on the **Input controls**
  tab in the runtime demo.
- **Color Combo Box** adds a split button with configurable theme and standard
  palettes, contrast filtering, automatic and transparent colors, and gradients.
- **Dropdown galleries** add scrollable lists, grouped icon grids and color
  palettes to `TLazRibbonPopupMenu`. The popup demo includes line spacing,
  borders, paper sizes, shapes and colors.
- The **Contents editor** groups the combo boxes together and offers
  **Progress Bar** from both item menus. Popup gallery image fields show image
  previews, and the Color Combo Box menu property can restore its built-in palette.
- The custom `TLazRibbonForm` title bar hides the window icon by default.
  Set `ShowTitleIcon = True` to display it.

Use Lazarus 4.8 with its bundled Free Pascal 3.2.2. Install or update the
runtime and design-time packages, then rebuild and restart the IDE. See the
[installation guide](../../INSTALL.md) for details.
